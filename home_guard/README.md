# Home Guard

Expo app for iOS and Android.

## Get started

```bash
pnpm install
pnpm android
```

## Structure

- `src/app/_layout.tsx` provides the app-wide theme.
- `src/app/(tabs)/` contains the tab navigator and Home and Explore screens.
- `src/components/` contains shared themed UI components.
- `src/constants/theme.ts` defines light and dark colors.
